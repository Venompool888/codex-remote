# Codex Remote 0.3.1

First stable distribution of the independent Android client and Remote Host.
This project is not affiliated with or endorsed by OpenAI.

## Downloads and identity

- Android package: `app.codexremote.android`.
- APK: `codex-remote-0.3.1.apk`, signed with a dedicated release key.
- Android 8.0 (API 26) or newer; targets API 36.
- Remote Host requires Node.js 20+ and a locally authenticated Codex CLI.
- `SHA256SUMS` verifies the release downloads; `SIGNING-CERTIFICATE.txt` records
  the APK signing certificate fingerprint for future update verification.

The release APK has a separate data directory from the `.debug` variant. Do not
uninstall an existing app to work around a signature mismatch: first verify its
package and signer. Existing private builds with a different signer cannot be
updated in place with this release.

## Included

- Compose interface with independent connections, projects, history, streaming
  conversations, Markdown, attachments, and work logs.
- Confirmed QR pairing, encrypted device credentials, credential rotation and
  revocation, and automatic reconnect.
- Scoped approvals, agent questions, remote skills/plugins/apps, notifications,
  artifact downloads, and persistent drafts.
- Host administration menu for pairing and device management, plus configuration
  of the public HTTPS address used in pairing QR codes.
- Immediate loading feedback when opening conversations.

## Deployment and limitations

Bind the Host to loopback and use HTTPS/WSS for internet access. Explicit HTTP is
supported only for trusted private connections and USB development; it provides
no transport encryption. No server address, account credential, pairing code, or
device connection is bundled with the app.

Codex capabilities vary with the installed CLI. Unsupported interactions fail
explicitly. After changing the CLI or deploying the Host, verify pairing, task
history, a turn, attachments, approvals, and reconnect in your own environment.
The automated release gate does not replace that deployment-specific check.

## Build verification

Run `./scripts/release-check.sh` for Host tests and compilation, Compose checks,
Android unit tests, debug/release Lint and APK assembly, and merged release
manifest validation. Release signing credentials are kept outside source control.
The unsigned APK produced by Gradle must be signed before installation.
