# Codex Remote 0.3.2

A maintenance release for conversation state recovery, on-device diagnostic export,
and host-backed permission controls. This is an independent community project and
is not affiliated with or endorsed by OpenAI.

## Changes

- Recover the Send/Stop button after missed completion events and refreshed history.
- Stop a running task opened after an app restart, using its server-provided turn ID.
- Keep newer turns running when older completion events arrive late; prevent late
  starts, text deltas and tool updates from reactivating completed state.
- Recover correctly after an interrupt error without resurrecting a completed turn.
- Add **Export logs** directly to the conversation overflow menu. Save a ZIP using
  Android's document picker or choose a recipient through the share sheet, without USB.
- Bundle bounded client logs, app state and up to 20 recent task status snapshots.
  Chat text, drafts, attachments and credentials are excluded. No automatic upload.
  Logs may still contain host names, task IDs, error text and paths; review before sharing.
- Resume diagnostic collection after malformed recent-task metadata and report the loss.
- Add an anchored permission menu with host-backed automatic review and configuration
  profiles; unsupported choices remain capability-gated.

## Upgrade

The signed APK uses the existing release certificate and package
`app.codexremote.android`, versionName **0.3.2**, versionCode **5**. Install it over
0.3.1 to retain existing app data. Do not uninstall to work around a signing error.
The separately installed Debug app has independent data and is not replaced.

Android 8.0 (API 26) or newer is required. The Host source package is also versioned
0.3.2; Node.js 20+ and a locally authenticated Codex CLI are required. Host deployments
remain user-managed. This release does not alter configured endpoints or credentials.
