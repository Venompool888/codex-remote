# Codex Remote 0.4.0

Subagent inspection and interface improvements, richer task history, and more reliable reconnect recovery. This is an independent community project and is not affiliated with or endorsed by OpenAI.

## Changes

- Inspect subagent history and tool output from the conversation, navigate nested child tasks, and return to the parent conversation.
- Browse subagents with status filters and clearer parent context. Direct input is offered only when the host explicitly supports it.
- Add stable, locally generated floral and geometric subagent avatars across lists, links, and the inspector.
- Use a compact grouped subagent panel with an expandable header. Conversations without subagents show no panel.
- Preserve drafts while steering an active turn and release interrupted history refreshes promptly after reconnecting.
- Recover cleanly when the Host app-server proxy fails initialization, allowing subsequent startup attempts.
- Improve nested question forms and exact scoped approval handling, and preserve plans, reviews, hooks, and aggregate diffs in task history.
- Improve accessibility of context-usage controls and clarify ancestry when a parent is hidden by a status filter.

## Upgrade

The release APK uses package `app.codexremote.android`, versionName **0.4.0**, versionCode **6**. It is intended for an in-place update of the official 0.3.2 release using the existing release certificate; do not uninstall to bypass a signing mismatch. The separately installed Debug app retains its own package and data.

Android 8.0 (API 26) or newer is required. The Host source package is versioned 0.4.0 and requires Node.js 20+ and a locally authenticated Codex CLI. Host deployments remain user-managed. No connection configuration, credentials, logs, or conversations are included.

## Scope and limitations

Additional task, workspace, host-management, and realtime-audio protocol/controller groundwork is included in the source. These capabilities are not all connected to Android screens and are not advertised as complete user-facing features. Subagent visibility depends on history and capabilities supplied by the connected host. Deployment-specific pairing, uploads, approvals, and restart behavior still require validation in the intended environment.

## Release validation

- Complete release gate passed: 177 Host tests (174 passed, 3 conditional skips), 398 Android unit tests, TypeScript compilation, Compose architecture checks, Debug/Release lint and APK assembly, and merged Release manifest checks.
- Five subagent emulator regressions passed, including hiding the panel for conversations without children and showing it when a child arrives.
- The signed 0.4.0 APK matches the official 0.3.2 signer and passes 16 KB ZIP alignment checks.
- In-place installation from official 0.3.2 to 0.4.0 and subsequent startup passed on a disposable emulator; first-install time was preserved.
- The public source snapshot and decompressed APK were scanned for private deployment markers and key material. Private development history, local configuration, logs, recordings, and device identifiers are excluded.

These checks do not replace deployment-specific live-host testing.
