# Codex Remote 0.4.0

本次更新重点带来子代理查看与管理功能，让你在手机上更方便地跟进多个子任务。

- **查看子代理执行过程**：从对话中打开子代理，查看任务历史、执行进展和工具输出，支持进入嵌套子任务并返回父任务。
- **子代理目录与状态筛选**：按全部、执行中、需关注、已完成筛选子代理，并显示父子任务关系，方便定位需要查看的任务。
- **自动生成专属小头像**：新增花朵、叶片、星形等图案与多种配色。同一子代理在列表、详情和任务链接中保持相同头像。
- **全新子代理面板**：采用可展开的分组布局，集中展示筛选和任务列表；没有子代理的对话不显示面板。
- **更丰富的任务过程展示**：支持展示任务计划、审查结果和汇总代码差异，方便回看任务执行过程。
- **更完整的交互表单与权限确认**：支持嵌套问题表单，以及针对具体命令、文件路径和权限范围的确认。
